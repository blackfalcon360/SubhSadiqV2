# Subh Sadiq & Subh Kazib 🌅

Shows the true dawn (Subh Sadiq, الفجر الصادق) and the false dawn (Subh Kazib, الفجر الكاذب) for your location:
times, what each looks like, a live "what is happening now" status, a timeline, and next-day / previous-day browsing.
The Subh Sadiq angle is selectable (Karachi, MWL, Umm al-Qura, Egyptian Survey, ISNA, Tehran, Qassim University field study, or custom).
The Subh Kazib window is an adjustable estimate. Time slider (± 48 h, 5-minute steps) with −1 h, −5 min, Now, +5 min, +1 h in one row. Languages: English, Urdu, Arabic (menu button, full RTL). Home-screen widget. Portrait only. Package: Subhsadiq.blackfalcon.jan. Works fully offline (no INTERNET permission).

Brought to you By: Black Falcon 🦅

## Build
Push to GitHub -> Actions -> "Build APK" -> download `SubhSadiq-APK`.
Local: `gradle assembleDebug` (JDK 17, Gradle 8.7+).
